ชุดเว็บไซต์เครื่องมือแผนที่ จังหวัดอุดรธานี (ฉบับปรับปรุง 15 ตุลาคม 2569)
=====================================================================
โครงสร้าง
  index.html               หน้าแรก (ลิงก์ไปยังเครื่องมือทั้งสอง)
  map-generator/index.html โปรแกรมสร้างแผนที่ขอบเขต
  data-map/index.html      แผนที่ระบายสีตามข้อมูล

สิ่งที่แก้ไขในฉบับนี้
1) ข้อมูลตำบลของอุดรธานีเป็น 156 ตำบล (เดิม 155) อำเภอเมืองอุดรธานีมี 21 ตำบล
   เพิ่มตำบลนาดี และตำบลนาข่าแยกเป็นรายตำบลตามข้อมูลทางการ
   ขอบเขตอำเภอสร้างจากการรวมขอบเขตตำบล จึงตรงกับขอบเขตตำบลทุกแนว
2) แก้แถบสลับ "อำเภอ/ตำบล" ที่หดหายบนหน้าจอที่ไม่สูง
3) แก้แผนที่ที่มีรูปร่างสูงล้นกรอบ
4) เปลี่ยนแหล่งข้อมูลขอบเขตและปรับข้อความเครดิตให้ตรงกับแหล่งใหม่

ข้อควรทราบเรื่องข้อมูล
- ข้อมูลขอบเขต ณ กุมภาพันธ์ 2562 เส้นขอบหยาบกว่าชุดเดิม หากมีการเปลี่ยนแปลงเขตการปกครองหลังจากนั้นอาจไม่ปรากฏ
- ไม่ใช่ข้อมูลทางการ ควรตรวจเทียบกับข้อมูลอย่างเป็นทางการก่อนใช้ในเอกสารสำคัญ

วิธีอัปเดตเว็บที่เผยแพร่แล้วบน GitHub
1) แตกไฟล์ zip นี้
2) เข้าที่เก็บ (repository) ที่เผยแพร่อยู่ กด Add file > Upload files
3) ลากไฟล์ index.html, โฟลเดอร์ map-generator และ data-map จากโฟลเดอร์ site มาวาง
   (ไฟล์ชื่อเดิมจะถูกแทนที่ ห้ามลากตัวโฟลเดอร์ site เอง)
4) กด Commit changes รอ 1-3 นาที แล้วรีเฟรชหน้าเว็บ (กด Ctrl+F5 เพื่อล้างแคช)
5) ทดสอบ: เปิดแท็บตำบล เลือกอำเภอเมืองอุดรธานี ต้องมี 21 รายการ และทั้งจังหวัดมี 156 รายการ

ก่อนเปิดสาธารณะ ควรตรวจสอบ
- เครดิตในหน้าเว็บ (ผู้จัดทำ แหล่งข้อมูลขอบเขต SheetJS ฟอนต์) ไม่ควรลบออก เพราะ CC BY กำหนดให้ต้องอ้างอิงแหล่งที่มา
- ใบอนุญาตของชุดข้อมูลต้นทาง (README ของโครงการระบุ CC BY 4.0 ยังไม่ได้ตรวจใบอนุญาตของ OCHA/กรมแผนที่ทหาร)
- ระเบียบของหน่วยงานเรื่องการเผยแพร่เครื่องมือในนามหน่วยงาน
