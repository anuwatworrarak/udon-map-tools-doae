ชุดเว็บไซต์เครื่องมือแผนที่ จังหวัดอุดรธานี
==========================================
โครงสร้าง
  index.html               หน้าแรก (ลิงก์ไปยังเครื่องมือทั้งสอง)
  map-generator/index.html โปรแกรมสร้างแผนที่ขอบเขต
  data-map/index.html      แผนที่ระบายสีตามข้อมูล

ทุกไฟล์เป็น HTML สถิต ไม่ต้องใช้ฐานข้อมูลหรือโปรแกรมฝั่งเซิร์ฟเวอร์

วิธีเผยแพร่ (เลือกอย่างใดอย่างหนึ่ง)
1) เว็บของหน่วยงาน: ส่งโฟลเดอร์ site ให้ผู้ดูแลเว็บ วางไว้ในโดเมนของหน่วยงาน
2) Netlify Drop: เข้าเว็บ Netlify เลือกเมนูอัปโหลดแบบลากวาง แล้วลากโฟลเดอร์ site ที่แตกไฟล์แล้วไปวาง จะได้ลิงก์ทันที
3) GitHub Pages / Cloudflare Pages: สร้างโครงการ นำไฟล์ในโฟลเดอร์ site ขึ้นไป แล้วเปิดใช้งานการเผยแพร่เว็บ
(ชื่อเมนูอาจเปลี่ยนตามผู้ให้บริการ)

ก่อนเปิดสาธารณะ ควรตรวจสอบ
- เครดิตในหน้าเว็บ: ผู้จัดทำ แหล่งข้อมูลขอบเขต (OpenGISData-Thailand, CC BY 4.0, ต้นทางกรมการปกครอง) SheetJS และฟอนต์ ไม่ควรลบออก เพราะ CC BY กำหนดให้ต้องอ้างอิงแหล่งที่มา
- ระเบียบของหน่วยงานเรื่องการเผยแพร่เครื่องมือในนามหน่วยงาน
- ทดสอบบนมือถือและเบราว์เซอร์หลัก โดยเฉพาะปุ่มบันทึกภาพและการนำเข้า Excel

ข้อควรทราบ
- ตัวอ่านไฟล์ Excel โหลดจาก cdnjs.cloudflare.com และฟอนต์จาก Google Fonts หากเครือข่ายบล็อกโดเมนเหล่านี้ ไฟล์ CSV ยังใช้ได้ แต่ Excel จะอ่านไม่ได้
- ข้อมูลที่ผู้ใช้นำเข้าประมวลผลในเครื่องของผู้ใช้ ไม่ถูกส่งไปยังเซิร์ฟเวอร์
